# ことばのカード

**声が届きづらいとき、文を大きく相手に見せるコミュニケーション補助アプリ**

---

## このアプリについて

騒がしい場所やマスク越しなど、声が届きにくい状況で、スマホの画面に大きな文字を表示して相手に伝えるアプリです。

- 文字を入力 → そのまま大きく表示（切り替えなし）
- 左にスワイプで新しいカードへ（前の文は履歴に自動保存）
- 画面右端の履歴ボタンで過去の文を呼び出し

---

## ファイル構成

このアプリは以下の**3ファイルのみ**で動作します。

```
voice-card/
├── index.html      ← アプリ本体（HTML・CSS・JavaScriptすべて入り）
├── manifest.json   ← ホーム画面へのインストール設定
├── sw.js           ← オフライン対応のサービスワーカー
├── icon-192.png    ← アプリアイコン（小）
└── icon-512.png    ← アプリアイコン（大）
```

Node.js・npm・ビルドツールは**一切不要**です。

## 使い方（ファイルをそのまま開く場合）

> ⚠️ PWA機能（ホーム画面追加・オフライン）はサーバーが必要です。  
> ローカルで試す場合は下の「静的ホスティングに置く」を参照してください。

---

## 静的ホスティングに置いて使う（推奨）

このフォルダの5ファイルを、静的ホスティングサービスにアップロードするだけで使えます。

### 方法 A：GitHub Pages（無料・初心者向け）

1. [https://github.com](https://github.com) でアカウントを作成・ログイン
2. 右上の「＋」→「New repository」でリポジトリを作成（名前は何でもOK）
3. 「uploading an existing file」のリンクをクリック
4. `index.html` / `manifest.json` / `sw.js` / `icon-192.png` / `icon-512.png` の5ファイルをドラッグ＆ドロップ
5. 「Commit changes」ボタンを押す
6. リポジトリの「Settings」→「Pages」→「Source: Deploy from a branch」→「Branch: main」→「Save」
7. しばらく待つと `https://あなたのユーザー名.github.io/リポジトリ名/` でアクセスできます

### 方法 B：Netlify Drop（最も簡単・アカウント不要）

1. [https://app.netlify.com/drop](https://app.netlify.com/drop) をブラウザで開く
2. `voice-card` フォルダをページにドラッグ＆ドロップ
3. 自動的にURLが発行されます（例：`https://xxxx.netlify.app`）

### 方法 C：ローカルで簡易サーバーを立てる

パソコンに **Python** が入っている場合：
```
cd voice-cardのフォルダのパス
python -m http.server 8080
```
→ `http://localhost:8080` で開く

## スマホのホーム画面に追加する（アプリとして使う）

上記の方法でURLを取得したあと、以下の手順でホーム画面にインストールできます。

**iPhone（Safari）の場合：**
1. Safariでアプリのページを開く
2. 画面下の「共有」ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」→「追加」

**Android（Chrome）の場合：**
1. Chromeでアプリのページを開く
2. 右上の「⋮」→「アプリをインストール」または「ホーム画面に追加」

## 使い方

| 操作 | 説明 |
|------|------|
| 画面をタップ | 文字入力モードになる |
| 文字を入力 | そのまま大きく表示される |
| 左にスワイプ | 現在の文を保存して新しいカードへ |
| 右端のボタン（≡） | 履歴ドロワーを開く |
| 履歴の項目をタップ | その文をカードに呼び出す |
| 履歴のゴミ箱ボタン | その項目を削除 |
| 履歴の「全消し」 | すべての履歴を削除 |

## トラブルシューティング

| 問題 | 解決策 |
|------|--------|
| `index.html` をダブルクリックしてもPWA機能が動かない | サーバー経由で開く必要あり（上の「静的ホスティング」参照） |
| フォントが表示されない | インターネット接続が必要（初回のみ）。一度開いてからはオフラインでも使えます |
| ホーム画面追加のメニューが出ない | SafariまたはChromeを使う。iOSはSafari必須 |
| 文字が表示されない | ブラウザをリロード（引っ張って更新） |

## 技術情報

- フレームワーク：**なし**（素のHTML+CSS+JavaScript）
- スタイル：グレースケールのみ・Material 3風デザイン
- データ保存：ブラウザのlocalStorage（端末内のみ・クラウド送信なし）
- PWA：manifest.json + Service Worker（オフライン対応）
- 対応ブラウザ：Safari（iOS 15+）、Chrome（Android 8+）、その他モダンブラウザ
